Finalidade Oficial do Aplicativo

O Hoop Streamer é uma aplicação móvel para Android desenvolvida exclusivamente para suprir a demanda de transmissões esportivas de basquetebol e outras modalidades de quadra.

O app utiliza as permissões de Câmera e Microfone unicamente no momento em que o usuário inicia uma transmissão ao vivo. Caso o usuário conecte sua conta Google, o aplicativo interage com a YouTube Data API v3 estritamente para obter a chave de transmissão e agendar o evento de live no canal do próprio usuário.

Para consultar o detalhamento de como os dados são tratados e protegidos, acesse nossa Política de Privacidade Oficial.
